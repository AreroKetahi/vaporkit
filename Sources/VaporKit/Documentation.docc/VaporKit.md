# ``VaporKit``

Build Vapor applications with compile-time abstractions and opt-in runtime features.

## Overview

VaporKit generates native Vapor code for routing and validation, keeping most
abstractions at zero runtime cost. Runtime capabilities such as automatic route
registration and the optional program entry point are separate: your application
pays only for the features it uses.
